# 从零重写的设计说明

## 当前第一步：论文图像输入

当前 `image_processing.py` 将 OpenCV 读出的 BGR 图像转为 RGB，固定缩放至 `256×256`，中心裁剪至 `224×224`，再使用预训练权重对应的 RGB ImageNet 均值和标准差。尺寸处理沿用论文描述；通道顺序和归一化公式已按用户要求与原项目的 BGR 实现区分。该模块不包含数据集路径或 YOLO 框处理。下文的可配置高宽与其他尺寸对照仍是后续研究方向，尚未实现。

## 为什么这样组织输入尺寸

可以把尺寸写死为 `224×224`，实现简单，但无法清楚比较 pic1 的长方形输入；也可以允许每张图任意尺寸，但参考图的特征网格、匹配块、批量处理和指标映射都会复杂很多。

当前建议采用中间方案：**尺寸是实验配置，不是全项目常量；一次实验内固定。** 原版 MVTec 与 pic1 是两份不同配置，不把它们的结果混为一次实验。配置使用命名的 `height`、`width`，避免 `(宽, 高)` 和 `(高, 宽)` 写反。

## 数据流

```text
读取图像和标签
    → 检查尺寸、通道、标注坐标
    → 明确的缩放 / 裁剪 / 补边策略
    → 预训练模型提取多层特征
    → 合成带位置的特征描述子
    → 参考图之间关联并筛出正常通道
    → 测试图最近邻距离
    → 按真实 (Hf, Wf) 恢复分数图
    → 映射回图像 (H, W) 并计算指标 / 保存可视化
```

每一箭头都应有可检查的输入和输出形状。原模型的卷积层可以接收不同空间尺寸，但后续代码不能假定网格是正方形。

## 保持可比性的规则

- 首先以原版代码和数据划分建立基线，再逐项改动；一次只比较一个变量。
- 模型输入尺寸、特征网格下采样、位置编码、平滑强度和参考集构成都是不同变量，应分别记录。
- 在相同测试图上比较原始分数和指标。显示时的热图归一化可能改变视觉印象，不代表模型分数更准。
- 若只有检测框，先约定框级评估方法；不要把框直接称作像素级真值掩码。

本说明描述重构方向，不代表以上模块已经实现。具体完成状态见 `REFACTOR_LOG.md`。
