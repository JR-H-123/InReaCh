## 目标与当前状态

目标：改善原图约 4×7 像素、最窄约 3 像素缺陷的漏检，逐步构建可理解、可验证的代码框架。
用户已选择方案 A：原尺度 224×224 切块、步长 112，不缩放块内图像。
数据已对齐，估计残余偏移 2–4 像素；约 40% 图片含缺陷；有 YOLO 检测框 txt。
40% 是用户估计的图片污染率，不是局部描述子污染率，也不是算法可靠性保证。
当前代码仅已有整图 RGB 预处理与 13 层骨干特征提取。本文件是设计，不表示新功能已实现。

## 方案比较与决定来源

- A 原尺度切块：保留原始局部像素，复用现有骨干；上下文缩小，计算量增加。用户已选择。
- B 切块后放大到 448×448：可能改变小缺陷的特征响应，但不增加真实细节，计算开销更大。暂不采用。
- 描述子重叠处理有位置归属与特征融合两种。建议首版采用位置归属，避免提前引入跨块特征融合；这是设计建议，尚未经用户单独确认。
- 建议提供坐标邻域约束及无空间约束对照。半径 4、8 原图像素是候选值，不是已验证参数。

## 数据与标签

建议使用明确的参考/验证/测试原图清单，不在框架中写死路径或划分比例。
同原图及其派生图不得跨集合；如有同工件的近重复图，用 group_id 分组划分。正式运行前确认清单。
参考集允许混有缺陷，建库接口不接收标签；标签只进入验证/评估。
默认支持 YOLO 检测框每行 class_id cx cy width height，坐标相对原图归一化。

评估使用原图坐标，无需将框裁成块标签。展示若需要块内框，应显式裁剪、平移。

## 切块几何

尺寸记法：图像 (H,W,C)，张量 (B,C,H,W)，坐标 (x,y)，网格 (Hf,Wf)。
单轴长度 L>=224 时：从 0 开始步长 112，补充 L-224 为最后起点并去重，完整覆盖原图。
L<224 时该轴仅一个起点 0，右侧/底部用边缘复制补齐，保留有效区域；补边不能成为建库或评估证据。
边缘复制为首版实现建议。一般边缘仍存在上下文截断，重叠不能保证与整图特征等价。
TileMeta 保存 image_id、tile_id、origin_xy、original_hw、valid_hw、padding。
块不再执行 256 缩放和中心裁剪，直接 RGB 归一化。batch_size 独立配置。

## 描述子与坐标契约

保持原版局部特征聚合思路，首版不增加额外的空间降采样；逐项核对原版描述子维度与聚合行为后实现。
共同网格拟采用最浅层 56×56（224 输入）。步长为 4 不意味着每个描述子只看 4×4 像素。
DescriptorSet 保存 features (P,D)、xy (P,2)、image_id、tile_id、grid_hw 和 validity。
坐标采用明确的网格单元中心约定，并与热图插值保持一致；不能把简单坐标公式冒称为精确感受野中心。
右/下贴边块可能与规则切块不共网格相位，不按展平索引合并，也不四舍五入假定完全重合。
首版位置归属：在每张原图上，按各覆盖块到最近块边缘的距离选择所属块；距离相同按 tile_id 固定决胜。
每个描述子仅当其中心位置属于当前块且落在有效原图内时参与建库。
这是空间区域归属，不保证不同相位描述子严格等距；后续关联使用实际浮点坐标。
保持这一策略可替换，不将重叠多个观测作为多个独立图像。

## 跨图关联、通道筛选与索引

以不同原图为关联单位，排除同 image_id；参考种子也按原图选取。
在原版互为最近邻关联的基础上增加可选空间门控：两轴原图坐标差均不超过 radius_px。
对齐比较要求图像使用一致的像素坐标系和尺寸；不一致时停止并报告，不偷偷缩放。
候选为空时该描述子不形成该次关联，不放宽约束或填入假匹配。
通道按不同 image_id 计数，每张图最多贡献一个成员；冲突按距离最小、稳定索引决胜。
通道长度与离散程度筛选保持可配置，不从“40% 污染”直接推导阈值。
参考图不足、无合格通道或空参考库时明确报错，不能退化成全量描述子建库。
坐标门控模式下，预测也查询坐标邻域内的正常描述子，避免训练/预测空间规则不一致。
预测无候选时返回 invalid 标志，保存覆盖率；不得作为正常分数 0。正式指标前需确认全部有效像素可评估。
距离采用明确一致的度量并记录，尤其不能混用欧氏距离和 FAISS 平方 L2。
通道构建与检索采用分块计算，限制内存；切块不代表总匹配开销下降。

## 预测与融合

各块描述子分数按真实 grid_hw 恢复并插值到 224×224，再移回原图。
重叠分数采用中心高、边缘低且严格大于零的权重，逐像素除以有效权重和；补边不参与。
仅有效预测参与融合，同时输出有效性图。不得在每块上单独 min-max 归一化后融合。
默认保存未经额外高斯平滑的分数，平滑作为独立对照参数。
输出原图大小 score_map (H,W)、valid_map (H,W)、原始图像级分数及配置。
缓存记录图像清单、预处理、权重节点、描述子、坐标及筛选参数，防止不同实验误用。

## YOLO 框评估（建议首版定义）

框不是像素级真值，不报告基于填满矩形伪掩码的像素 AUROC。
阈值只用验证集选取，测试集冻结。无已确认清单与标注完整性时，仅报告探索性结果。
阈值化原图分数得到 8 连通异常区域，首版不设会删除小缺陷的最小面积过滤。
每个区域取最高分像素为定位点，平分时按坐标顺序决胜。
以定位点落在真实框内建立候选关系，采用最大基数的一对一匹配，固定排序保证确定性。
报告框召回率=匹配框数/总框数，以及未匹配预测区域数/图。另报告异常覆盖面积比例，暴露大面积误报。
该规则是框监督下的定位代理指标，不声称分割准确；大的合并区域也可能掩盖定位不足，需要保留可视化。
误报解释依赖完整标注；漏标区域只能称未匹配区域，不能确定为误报。
图像级分数初始采用有效区域最大异常分数；只有正常/异常两类均存在且标签可信时报告 AUROC。
分别记录阈值曲线、推理时间、显存及有效预测覆盖率，不仅展示彩色热图。

## 拟议模块与接口

| 文件 | 输入 → 输出 | 责任 |
| --- | --- | --- |
| config.py | 实验参数 → 校验后的配置 | 几何、批量、描述子、关联、评估参数 |
| dataset.py | 原图清单/YOLO txt → ImageRecord/Box | 划分检查与标签解析，缺失标签语义明确 |
| tiling.py | RGB 原图 → 块与 TileMeta | 完整覆盖、补边、位置归属 |
| feature_extraction.py | 块张量 → 13 层特征 | 复用当前实现 |
| descriptors.py | 多层特征/TileMeta → DescriptorSet | 局部聚合、网格、有效性与原图坐标 |
| association.py | 无标签参考描述子 → 通道 | 跨图候选、互近邻、独立原图支持计数 |
| memory_bank.py | 合格通道 → 正常索引 | 筛选结果与坐标、缓存一致性 |
| prediction.py | 测试描述子/索引 → 分数与有效性 | 一致的距离及空间检索规则 |
| stitching.py | 块分数/TileMeta → 原图分数 | 加权融合、有效覆盖 |
| evaluation.py | 原图分数/验证标签 → 指标 | 阈值、框级匹配、图像级指标 |
| pipeline.py | 配置与原图清单 → 模型产物/结果 | 串联流程，建库与评估标签隔离 |

image_processing.py 保留整图基线及 RGB 工具；第一轮不为目录美观大规模搬移已有文件。
后续框架阶段先定义数据结构、接口、调用入口；未实现算法明确抛出 NotImplementedError，不返回伪分数。

## 实施顺序与验证要求

1. 框架与契约；2. 切块、YOLO 与坐标；3. 单图描述子；4. 小样本通道/建库；5. 预测融合；6. 固定划分对照。
每步先用中文解释输入输出，再实现一项可检查功能，实际验证结果追加 REFACTOR_LOG.md。
关键验证：非整除边界覆盖、小图补边、YOLO 转换、重叠归属、不同网格相位、同原图排除、无候选、空通道、常量热图融合、一对一框匹配。
正式实验比较整图基线、原尺度切块、空间约束，避免一次改变所有参数。全部原图、缺陷框与评估口径保持可追溯。
