# 面向细小缺陷的 InReaCh 改进思路

临时汇报材料 · 2026-10-23

用途：制作约8–10分钟的阶段汇报PPT。建议9页，重点放在问题、改进思路及验证计划，代码进度放在最后。以下“页面内容”可直接放入PPT，“讲解补充”用于演讲备注，“配图建议”是待制作示意，不是已有实验结果。

当前定位：基于 ICCV 2023 InReaCh 的原尺度重叠切块扩展。已完成输入、描述子和建库前处理，检测链路尚未完成，尚无准确率提升结论。文中的“新思路”指本项目的改进方向，不声称这些单项技术是首次提出。

---

## 第1页｜研究目标：让细小缺陷在处理过程中保留下来

### 页面内容

- 目标：改善工业图片中细小缺陷的漏检。
- 关注尺度：原图中约4×7像素，最窄处约3像素。
- 基本方向：保留局部像素细节，利用跨图对应关系筛选正常特征。
- 核心思路：原尺度重叠切块 + 原图坐标追踪 + 跨图空间约束。

### 讲解补充

目前首先解决的是信息保留问题。缺陷如果在输入缩放时已被弱化，后续特征提取和异常评分就很难恢复它。我们沿用 InReaCh 跨图筛选正常模式的主线，对输入组织和空间关联进行扩展。

### 配图建议

一张原图，标出一个小缺陷，再放置局部放大图。标注“局部放大仅用于展示”，避免把展示放大与模型输入放大混淆。

## 第2页｜现有输入流程的局限：细节在缩放与裁剪中损失

### 页面内容

- 当前整图基线：847×711 → 256×256 → 中心裁剪224×224。
- 3像素宽度经缩放后，几何尺寸约为0.9–1.1像素。
- 中心裁剪还可能排除靠近原图边缘的缺陷。
- 假设：保留原始像素尺度，有望提高细小缺陷的特征响应。

### 讲解补充

0.9–1.1像素来自两轴缩放比例的估算，说明细节可能被插值弱化，不表示已经测得缺陷完全消失。这里描述的是新版已有的整图基线；旧项目训练与测试预处理存在差异，不能把这个流程概括成所有原版运行配置。

### 配图建议

并列“原图局部”“整图缩放后的对应局部”“原尺度切块局部”。同一缺陷使用相同展示倍率，方便观察保留的信息；图片制作后再描述观察结果。

## 第3页｜思路一：在原图尺度进行重叠切块

### 页面内容

- 图块大小224×224，滑动步长112，内部规则区域约50%重叠。
- 块内不缩放，保留缺陷原有像素尺寸。
- 末块贴齐图像边界，覆盖整张原图。
- 当前847×711图片产生7×6，共42块。

### 讲解补充

“不缩小图块”负责保留像素细节；“重叠”让位于一块边缘的缺陷，有机会在另一块中获得更完整的上下文。二者作用不同。224和112是首轮配置，尚未证明最优。末块贴边时重叠比例可能大于50%。重叠不能完全消除图块边界效应。

### 配图建议

在原图上叠加相邻两个半透明224×224方框，标出112像素步长。把一个小缺陷画在第一块边缘、第二块内部。

## 第4页｜思路二：描述子携带原图坐标

### 页面内容

- 复用现有13层骨干特征，多层信息聚合到最浅层网格。
- 单块224×224 → 56×56网格 → 3136个1024维描述子。
- 每个描述子保留：原图ID、图块ID、原图坐标、有效性。
- 这些信息支持跨图匹配、重叠处理及最终热图还原。

### 讲解补充

把图像切开以后，必须知道每个局部特征原来来自哪里。对于网格行列(r,c)，坐标采用单元中心约定：

x = 图块起点x + (c+0.5) × 图块宽 / 网格宽

y = 图块起点y + (r+0.5) × 图块高 / 网格高

这个位置是统一的空间索引，不是卷积感受野的精确中心。最浅层仍有约4像素空间步长，所以保留原图输入并不保证3像素缺陷一定可检出。后续仍需验证局部池化和深层特征是否弱化小缺陷。

### 配图建议

“原图位置 → 图块局部网格 → 带坐标的特征点”，用同一颜色连起三个位置。公式可放备注而不放主页。

## 第5页｜思路三：重叠观测不能变成重复的正常证据

### 页面内容

- 同一缺陷可能同时出现在多个重叠图块中。
- 建库以原图为独立样本，不能把这些块视作不同图片。
- 同一原图坐标优先归属于离块边缘更远的覆盖块。
- 后续通道支持数按不同原图统计，每条通道每张原图最多贡献一次。

### 讲解补充

如果把所有块直接当成独立图像，同一个异常在重叠区的重复出现，可能被误认为来自多张图片的稳定模式。为此，建库前做位置归属筛选；预测则保留重叠观测，未来用于分数融合。

位置归属已实现，通道中的独立原图支持计数仍待实现。归属处理的是连续原图空间；不同图块的特征网格可能错相位，因此不能简单按数组下标去重，也不能宣称已消除全部相关性。

### 配图建议

同一缺陷出现在两个相邻块中，用连线指回同一个原图ID；旁边展示建库时选取一侧、预测时保留两侧的示意。

---

## 第6页｜思路四：利用对齐条件，限制跨图匹配范围

### 页面内容

- 图片已对齐，仍可能残留2–4像素位置偏差。
- 拟在另一张图的对应坐标附近寻找特征匹配。
- 用空间邻域容纳偏移，同时减少不同结构之间的混淆。
- 搜索半径先比较±4、±8像素，并保留无空间约束对照。

### 讲解补充

严格逐坐标匹配可能把正常错位判成异常；范围过大又可能让缺陷匹配到附近正常纹理。空间邻域需要通过实验选择，当前±4、±8只是候选值。

计划在候选范围内采用互为最近邻关联，再按跨图支持和通道离散程度筛选正常特征。预测阶段也应遵循一致的空间规则。目前关联模块还未实现。如果相似缺陷在多张图片的相同位置重复出现，它仍可能形成稳定通道，这项风险不能单靠空间约束解决。

### 配图建议

两张对齐图片，左图标一个描述子，右图在对应位置画小搜索窗口；窗口外的相似纹理用淡色表示。

## 第7页｜整体方法：建库与检测共用坐标体系

### 页面内容

建库路径：

混有缺陷的参考原图 → 重叠切块 → 多层描述子与原图坐标 → 原图汇总及位置归属 → 跨图关联 → 正常通道筛选 → 正常参考库

检测路径：

待测原图 → 重叠切块 → 多层描述子与原图坐标 → 正常库检索 → 图块异常分数 → 原图加权融合 → 缺陷定位

- 建库阶段限制重复证据；检测阶段利用重叠观测。
- YOLO框只进入评估环节。
- 分数按真实坐标还原，补边区域不参与有效结果。

### 配图建议

上下两条横向流程线，在“正常参考库”处连接。已完成部分用实色，待实现部分用虚线；标签读取单独连接“评估”，不要连向正常库筛选。

## 第8页｜怎样验证：分别检验各项改动是否有效

### 页面内容

| 实验 | 主要目的 |
| --- | --- |
| 整图缩放基线 | 建立相同数据划分下的对照 |
| 原尺度无重叠切块 | 检查保留像素尺度的贡献 |
| 原尺度重叠切块 | 检查重叠上下文对边界缺陷的帮助 |
| 重叠切块 + 空间邻域 | 检查对齐信息是否减少错误匹配 |

- 关注：框级检出率、未匹配预测区域数、异常覆盖面积。
- 同时记录：推理时间、内存/显存、有效预测覆盖率。
- 同一实验使用固定原图划分，阈值在验证集确定。

### 讲解补充

上述为实验计划，尚无结果。比较切块方案时，应保持相同骨干、RGB归一化和评分规则；尽量逐项改变因素。整图基线的中心裁剪可能丢失部分边缘标签，要记录测试覆盖范围，并区分共同可见区域的比较和完整图像的检出比较。

当前pic1共158张图、300个框，所有图像均有缺陷，无法用该子集计算正常/异常图像级AUROC。检测框也不是像素级分割真值，因此不能把填满矩形的掩码作为精确像素标签。未确认标注完整时，用“未匹配区域”描述预测，避免直接认定为误报。

### 配图建议

预留“实验组—检出率—未匹配区域/图—耗时”表格，所有结果位置写“待实验”，不填假设性数字。

## 可直接用作开场的简短讲稿

本次重构主要针对细小缺陷漏检。我们关注的缺陷在原图中通常只有4×7像素，最窄约3像素；整图缩放后，这些细节可能只剩一个像素左右。因此，新方案首先采用原尺度重叠切块，让小缺陷保留原有像素。随后，为每个描述子保存原图坐标，结合图片已对齐的条件，在对应位置附近建立跨图关联。同时，建库时限制同一原图重叠区域的重复贡献，避免把重复出现的缺陷当作独立正常证据。目前已完成输入、描述子和建库前处理，下一步实现通道筛选与检测，并通过固定数据划分下的对照实验验证效果。
