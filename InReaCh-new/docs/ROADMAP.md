# 重构路线（初学者顺序）

每一步先解释概念、写一个能证明行为的小测试，再编写对应代码并记录实际运行结果。下一步以前一步通过为条件。

| 步骤 | 要学和要做的事 | 最小验证 |
| --- | --- | --- |
| 0. 建立工作区 | 保留原代码快照，写清输入尺寸和实验约定。 | 检查目录、快照校验值及文档。 |
| 1. 图像输入 | 从任意路径读取图像，转换为 RGB，缩放至 `256×256`、中心裁剪至 `224×224`，按预训练权重参数归一化。 | 合成图的裁剪像素、张量形状与通道数值正确；真实图可读。 |
| 2. 数据组织 | 在明确训练和测试划分后，组织图像路径及批量读取；历史阶段不处理 YOLO 框；2026-10-23 已新增解析。 | 参考图和测试图名单可复现且互不重叠。 |
| 3. 模型特征 | 加载相同的预训练骨干和特征节点，显式设置 `eval()` 与归一化。 | 单张图输出各层特征的实际 `(Hf, Wf)`。 |
| 4. 描述子 | 将多层特征映射到共同网格，再加入分别计算的高、宽位置。 | 描述子数量等于 `Hf×Wf`；长方形例子通过。 |
| 5. 参考通道 | 实现块匹配、通道筛选和最近邻索引。 | 小型人工数据能得到可手算的匹配结果。 |
| 6. 预测 | 将距离还原为 `(Hf, Wf)`，再映射到输入图像大小。 | 正方形及长方形热图均与输入图像对齐。 |
| 7. 评估与复现 | 固定数据划分、参数和种子，保存原始分数与指标。 | 小样本端到端通过，并可重复得到相同结果。 |
| 8. pic1 对照 | 在同一划分下逐项比较输入尺寸及其他设置。 | 记录可比较的指标，而不只保存热图。 |

截至 2026-10-21，已完成步骤 0、步骤 1 和步骤 3 的单图骨干特征验证；当时旧 YOLO 框代码已移除。2026-10-23 新增了数据发现与 YOLO 解析，正式数据划分尚未完成；描述子、通道和评估仍待实现。实际验证记录见 `REFACTOR_LOG.md`。
